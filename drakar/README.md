# Drakar Support

Drakar is a native macOS app to drive Claude Code: the conversation, the tool calls, the
permission prompts and the diffs, in a window as light as Zed. It runs the `claude` (or
`codex`) you installed, and is open source at [mgcrea/drakar](https://github.com/mgcrea/drakar).

## Open an issue here

[Open an issue](https://github.com/mgcrea/support/issues/new?labels=drakar&title=%5Bdrakar%5D+)
and it will be labelled `drakar`. Please include your Drakar version (Settings › About),
your macOS version, the output of `claude --version` (or `codex --version`), and what you
did, expected, and saw. Drakar speaks an undocumented protocol, so the CLI's version often
explains a break: the footer says when yours is outside the versions Drakar was tested with.

A session's transcript can hold your code, file paths and prompts. Trim it to what shows the
problem before pasting any of it here.

## Everything else

The [website](https://drakar.mgcrea.io) has the download. For a security problem, follow
[SECURITY.md](https://github.com/mgcrea/drakar/blob/main/SECURITY.md) or email
[security@mgcrea.io](mailto:security@mgcrea.io), never a public issue.

For anything else you would rather not post publicly, email
[support@mgcrea.io](mailto:support@mgcrea.io).
